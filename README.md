# Konverter KML/KMZ ke CSV — V8

- Tombol bebek hijau untuk mengunduh CSV.
- Koordinat diekspor dengan tepat enam digit desimal dan dibungkus formula teks Excel (`="-6.306300"`) agar nol di belakang tetap terlihat ketika dibuka langsung di Excel.
- Pertahankan kolom CSV, filter Homepass/Pole, dan estimasi drop cable +25 m.

Catatan: untuk sistem yang membutuhkan koordinat sebagai nilai numerik murni, impor CSV melalui Data > From Text/CSV dan atur kolom koordinat sesuai kebutuhan, atau gunakan ekspor tanpa formula Excel.
